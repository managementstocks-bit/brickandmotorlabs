Blix Marble Run 2

Age 8+ 220+ Parts $107.92 CAD

Blix Marble Run 2 takes marble track building to the next level with a motorized system that keeps the action going. Using pillars, curves, slopes, and a dedicated track system, kids can build 4 different models and create exciting courses where marbles move continuously through the track. Along the way, they explore how motors, gravity, and motion work together while enjoying endless opportunities to build, test, and improve their designs.
